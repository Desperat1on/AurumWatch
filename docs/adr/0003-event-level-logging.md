# 事件级日志，按天分文件，保留 30 天

控制台消失后，触发与故障警告需要一个可回查的去处。日志只记事件——触发、故障警告、故障出现与恢复、程序启停、设置保存、弹窗失败——不记录每轮行情；按天分文件（如 `logs/aurumwatch-2026-09-14.log`），自动清理 30 天前的文件，放在 exe 同目录的 `logs/` 下。

## Considered Options

- 单文件按大小轮转（如 1MB × 5 份）：实现略简单，但「回查某天发生过什么」不如按天分文件直观。

## Consequences

- 不记录逐轮行情，日志无法还原价格曲线；历史行情记录与图表仍是明确的「不做」范围。
- 与主窗口「事件记录」分工：事件记录是内存态近况（重启即失），日志负责长期回查。
- 事件级日志量极小（一天通常几行到几十行），无需考虑体积。
