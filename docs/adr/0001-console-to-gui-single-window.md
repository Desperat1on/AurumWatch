# 控制台程序改为单窗口 GUI 应用

原实现是前台控制台窗口（行情上屏）+ 右下角弹窗提醒。控制台上屏需要自行折行、原地刷新，本身就是持续出错源（见 ticket 05 的折行错位）。在「开箱即用 + 图形化设置」的新要求下，改为 tkinter 单窗口 GUI：一个常驻主窗口显示行情与事件记录，设置从主窗口打开，预览与真实弹窗共用同一套绘制代码。控制台版连同折行/原地刷新代码与对应测试一并删除；触发判定、故障记账等纯函数原样保留。

## Considered Options

- 保留控制台 + 独立设置窗口：改动最小，但双击后出现「黑窗 + 设置窗」两个割裂的东西，从控制台唤出设置窗还要额外做按键监听。
- 控制台 + 独立设置程序（改配置文件）：两个进程、两种心智模型，体验最差。

## Consequences

- 失去控制台的滚动回看：由主窗口「事件记录」（近若干条）与落盘日志弥补（见 ADR-0003）。
- 主窗口与弹窗共用一套主题设置，因此设置里只有一组配色/字体，不是两组。
- 关闭主窗口即退出程序（不做系统托盘）。
