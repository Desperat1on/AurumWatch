# 02: 国内金价越线，右下角弹窗提醒

**What to build:** 让国内金价具备到价提醒：在主脚本顶部配置区填写国内「涨破」「跌破」阈值（留空或填 0 的方向不启用）；价格越线时屏幕右下角弹出一个不打断工作的小窗——方向、市场、现价、阈值、数据时间，附一声短提示音，30 秒自动消失、点击即关。提醒后继续监视；价格回落越过重新武装带（阈值 × 0.1%）后再次越线会再次提醒，贴着阈值抖动不会反复打扰。触发判定核心以纯函数实现（一次读数与当前状态进，提醒事件与新状态出），随票交付覆盖各场景的单元测试。

## Comments

实现记录（2026-09-12）：

- **判定核心**：`evaluate_thresholds(market, quote, state, rearm_ratio)` 纯函数（一次读数 + 配置 + 当前状态进，提醒事件 + 新状态出），市场无关——票 03 只需在国际配置项填阈值即可接入。边界口径「到达即算」：涨破 ≥、跌破 ≤，重新武装线同样含端点（回落恰好到 949.05 即重新武装）。触发后该方向进入已触发，须回落越过「阈值 ∓ 阈值 × 比例」才重新武装。`TriggerState.armed` 为方向集合，涨破、跌破各持一位、互不干扰。
- **配置区默认全留空**（两个市场、四个方向均 `None`，不提醒）；数值按 `Decimal("...")` 格式填写。
- **弹窗**：常驻后台线程持有 Tk 根窗，主循环只往队列投递提醒（主循环在 `time.sleep` 期间照常轮询，不受弹窗影响）。自绘无边框置顶窗贴屏幕工作区右下角（`SPI_GETWORKAREA`，避开任务栏），多个弹窗自下而上叠放。
- **不抢焦点的三个坑与修法**（均实测）：① Tk 根窗创建后 Windows 会**延迟**送来一次激活（当时窗口已隐藏），用 `after(250)` 延迟把前台还给原窗口，且只在前台确属本进程时才归还；② 弹窗必须先把窗口建出来（`update_idletasks`）再设 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`，抢在首次映射前生效——设早了拿不到顶层包装句柄，等于没设；③ 点击关闭绑定在**鼠标松开**（`<ButtonRelease-1>`），按下即销毁会让松开事件落到弹窗底下的窗口上。
- **提示音**：`winsound.MessageBeep(MB_ICONASTERISK)`，失败时退化 `Beep(880, 180)`；`SOUND_ENABLED = False` 可关。
- **控制台**：触发时刻写一行带时间戳的日志（沿用票 01 的整分对齐刷新），日志行会顶替旧帧位置、留在滚动区；市场段落增加「距触发还差 X」/「已触发；回落至 X 以下重新武装（还需回落 Y）」与状态行。
- **验证**：`python -m unittest discover -s tests` 共 42 例全绿（新增 `tests/test_alerts.py` 29 例，覆盖票面全部场景 + 控制台文案）；弹窗冒烟实测（截图目视、前台窗口全程不变、真实鼠标点击即关、到时自动消失）；真实数据端到端——把国内涨破阈值临时设在现价（940.00）下方 0.5 元，首轮即触发：控制台出现带时间戳日志、状态转「已触发待回落」、重新武装线 938.56 显示正确，随后连续 5 轮照常刷新，未重复提醒。临时脚本与截图已删，配置文件未做改动。
- **留给人工的验收项**：提示音的听感（代码路径已验证无异常，响度需人耳确认）；默认 30 秒停留（冒烟以 8 秒验证了自动消失机制，时长只是配置值）。
- **代码审查（Standards + Spec 双轴）后的修正**：Spec 轴抓到两个真 bug，均已修复并复验——① `winsound.MessageBeep` 成功时返回 `None`（本机实测），原 `if not MessageBeep(...): Beep(...)` 会让每次提醒响两声、且失败退化路径反而不执行，改为 try/except 退化；② `start_notifier` 未检查 `_ui_ready.wait()` 的超时返回值，Tk 初始化卡住会误报弹窗可用，已按返回值判断。Standards 轴无硬违规，判读项处理三处：提取 `enabled_directions(market)` 消除判定/渲染/状态三处重复、`margin` 更名 `distance_to_line`、测试提取 `fired_state`/`console_text` 助手消除样板。审查提出的「国内、国际互不串扰缺测试」按票面归属留给票 03。
