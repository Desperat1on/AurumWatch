# 02: 国内金价越线，右下角弹窗提醒

**What to build:** 让国内金价具备到价提醒：在主脚本顶部配置区填写国内「涨破」「跌破」阈值（留空或填 0 的方向不启用）；价格越线时屏幕右下角弹出一个不打断工作的小窗——方向、市场、现价、阈值、数据时间，附一声短提示音，30 秒自动消失、点击即关。提醒后继续监视；价格回落越过重新武装带（阈值 × 0.1%）后再次越线会再次提醒，贴着阈值抖动不会反复打扰。触发判定核心以纯函数实现（一次读数与当前状态进，提醒事件与新状态出），随票交付覆盖各场景的单元测试。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 配置区可设国内「涨破」「跌破」阈值；留空或填 0 的方向不启用、不提醒
- [ ] 国内金价 ≥ 涨破阈值或 ≤ 跌破阈值时，右下角弹出无边框小窗，含方向、市场、现价、阈值、数据时间
- [ ] 弹窗不抢焦点、不阻塞后续轮询；30 秒自动消失，点击立即关闭
- [ ] 触发时伴随一声短提示音，可在配置区关闭
- [ ] 触发后脚本继续运行；控制台留有带时间戳的日志，并显示该市场状态（监视中 / 已触发待回落）
- [ ] 控制台显示现价距各阈值的距离
- [ ] 价格停留或贴着阈值抖动时不重复提醒；回落越过重新武装带后再次越线会再次提醒（缓冲比例可配置）
- [ ] 脚本启动时若已越线，第一次读数即提醒
- [ ] 触发判定核心的 `unittest` 用例通过：基本涨破/跌破触发、未达阈值不触发、抖动不重复触发、回落再触发、启动即越线、留空阈值不参与、涨破与跌破互不干扰
