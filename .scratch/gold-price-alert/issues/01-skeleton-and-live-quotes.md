# 01: 骨架贯通——双击运行，国内、国际金价实时上屏

**What to build:** 双击「启动金价监视.bat」即开始监视：控制台上下两段分别显示国内金价（沪金99，元/克）与国际金价（伦敦金，美元/盎司）的现价和行情数据时间，每 60 秒自动刷新，关闭窗口即停止。本票把整个功能的骨架一次贯通：专用 Conda 环境、两个数据源的取数（含 GBK 解码与 Referer 头）、中文名启动器、出错不闪退。不含阈值与任何提醒。

**Blocked by:** 无（可立即开工）

**Status:** ready-for-agent

- [ ] 专用 Conda 环境 `aurum`（Python 3.13）创建完成，第三方依赖仅 `requests`
- [ ] 双击「启动金价监视.bat」即可运行，不需要命令行、不需要手动激活环境
- [ ] 控制台分两段显示国内金价与国际金价，各含现价和数据时间
- [ ] 每 60 秒自动刷新；间隔可在主脚本顶部配置区修改
- [ ] 显示数值与行情网站一致（2026-09-12 实测参考：国内约 940 元/克，国际约 4348 美元/盎司）
- [ ] 脚本异常退出时窗口停住并显示错误，双击场景不闪退
- [ ] 关闭窗口即停止监视（Ctrl+C 同样有效）
