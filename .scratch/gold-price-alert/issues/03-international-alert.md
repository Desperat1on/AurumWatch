# 03: 国际金价接入同一套提醒

**What to build:** 国际金价（伦敦金，美元/盎司）接入与国内完全相同的提醒机制：配置区填写国际的「涨破」「跌破」阈值（按美元/盎司），越线弹出同样式的右下角小窗；两个市场各自独立判定、互不干扰，控制台两段各显示各的状态与距阈值距离。国内、国际的阈值可同时启用，也可只启用其一。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 配置区可设国际「涨破」「跌破」阈值，按美元/盎司填写
- [ ] 国际金价越线时弹出右下角提醒，数值以美元/盎司显示、两位小数
- [ ] 国内、国际在同一时刻可各自独立触发与提醒，状态互不覆盖、互不阻塞
- [ ] 控制台两段分别显示各自的市场状态与距阈值距离
- [ ] 只启用一个市场（另一个留空或填 0）时，行为与该市场单独启用时一致
