# 03: 国际金价接入同一套提醒

**What to build:** 国际金价（伦敦金，美元/盎司）接入与国内完全相同的提醒机制：配置区填写国际的「涨破」「跌破」阈值（按美元/盎司），越线弹出同样式的右下角小窗；两个市场各自独立判定、互不干扰，控制台两段各显示各的状态与距阈值距离。国内、国际的阈值可同时启用，也可只启用其一。

**Blocked by:** 02

**Status:** done

- [x] 配置区可设国际「涨破」「跌破」阈值，按美元/盎司填写
- [x] 国际金价越线时弹出右下角提醒，数值以美元/盎司显示、两位小数
- [x] 国内、国际在同一时刻可各自独立触发与提醒，状态互不覆盖、互不阻塞
- [x] 控制台两段分别显示各自的市场状态与距阈值距离
- [x] 只启用一个市场（另一个留空或填 0）时，行为与该市场单独启用时一致

## Comments

实现记录（2026-09-12）：

- **票 02 已把判定核心做成市场无关**（`MARKETS` 两项、状态按代码分别持有），本票的主要工作是补齐「两个市场互不串扰」这条性质的可测缝与验证，而非新写一套国际逻辑。
- **缝的扩展**：原结构里「各市场独立判定」只存在于 `run()` 的循环内联代码中，无法在纯函数层断言（票 02 审查已把这条测试留给本票）。新增两个纯函数，均在既有的「触发判定核心」缝上、不碰网络与 UI：
  - `evaluate_markets(markets, quotes, states, rearm_ratio)`——一轮刷新对各市场独立判定，返回本轮全部提醒与各市场新状态；`quotes` 缺某市场代码（取数失败）则该市场保持原状态、不产生提醒。
  - `render_frame(markets, quotes, errors, states, rearm_ratio)`——渲染整帧控制台内容（两段各显示各自的市场、单位、距阈值距离与状态，段间空行）。
  `run()` 改为调用这两个函数，行为不变。
- **测试**：新增 `tests/test_markets.py`（12 例）——同一轮两市场各自越线各自提醒、一个市场越线不动另一个的状态、各自按自己阈值的 0.1% 重新武装（949.05 与 4395.60）、缺读数的市场不参与判定也不被改写、传入状态表不被就地修改、只启用其一（另一个留空或填 0）时另一市场保持静默、控制台两段各显示各自单位与状态。全套 54 例通过。
- **真实数据端到端**：临时把两个市场的「涨破」阈值设到现价下方（国内 939.50、国际 4345.35），跑真实 `run()` 主循环 4 轮——首轮两个市场各自触发（控制台两行带时间戳日志、两段状态均转「已触发待回落」、重新武装线各按自己阈值计算：938.56 与 4341.00），第 2–4 轮均无重复提醒，状态各自保持。临时脚本已删，仓库配置未改动。
- **弹窗冒烟**：国内涨破（红）与国际跌破（绿）两条提醒同时投递，截图目视确认样式与单市场一致、单位与两位小数正确、多个弹窗自下而上叠放、不抢焦点。
- **留给人工的验收项**：无新增（提示音与弹窗停留时长沿用票 02 的验收口径）。
- **代码审查（Standards + Spec 双轴）**：Standards 轴无硬违规，两条判断题处理如下——① 测试文件与 `test_alerts.py` 的 fixture 重复（本地常量原名 `MARKETS` 易被误读为生产配置）已改名 `BOTH_MARKETS`、删掉不实注释，重复本身保留（两文件自洽、各验各的行为）；② `render_frame`/`evaluate_markets` 的 `quotes` 与 `errors` 是平行映射，判为票 04 的领域（按市场记录失败时长会重塑这条接口），本票不预先造类型。Spec 轴抓到两条实锤，均已修复：① 「控制台两段」原断言用整帧 `assertIn`，颠倒段序、删掉段间空行都能全绿——已改为整帧逐行比对，两个变异实测都能抓住；② 票据与测试注释误称两市场「量级差两个数量级」（实际 940 与 4348 只差约 4.6 倍），已改。另记一条归票 04 的前置发现（见票 04 的 Comments）。
