# 06: 单实例与开机自启

**What to build:** 重复双击不会跑出第二份监视——程序已在运行时，第二次启动把已有主窗口带到前台后静默退出。设置窗口里有[开机自启]开关：勾选时把 exe 绝对路径写入当前用户的 Run 注册表键，取消时删除；从源码运行时该开关置灰并说明原因（不把 Python 路径写进注册表）。

**Blocked by:** 03（设置落地）

**Status:** ready-for-agent

- [ ] 程序运行中再次启动：不产生第二份监视，已有主窗口被带到前台
- [ ] [开机自启] 勾选/取消正确写入/删除当前用户 Run 键，值为 exe 绝对路径
- [ ] 重启电脑后自启生效：程序开始监视
- [ ] 从源码运行时开关置灰并说明原因
- [ ] 取消自启后注册表无残留
