# 08: 主窗口几何——记住你摆的地方

## Comments

实现记录（2026-09-14）：

- **存的形状**：`window.geometry`，值就是 Tk 的 `wm geometry` 那种写法（`960x640+120+80`，负号表示落在屏幕左／上之外）——程序自己写、自己读，**只认这一种形状**（手改成 `800x600` 这种少半截的当没记过，按默认位置开窗并说明一句）。解析（`config.parse_geometry`／`GEOMETRY_PATTERN`）在配置层（那是配置值的形状），落位计算（`main_window.visible_geometry`）在主窗口层（先例：`popup.corner_origin` 也是纯函数）——两处都能单测。
- **不是设置项**：设置窗口上没有这一项（它是状态，不是偏好）。但设置窗口保存的是**整份**配置，所以 `_draft()` 把 `window` 段原样带上——不带的话，在设置里改一次配色就把记下的位置抹了。
- **什么时候写**：「关闭主窗口即退出」那一刻（`MainWindow._close` 先记几何再 destroy，销毁之后就问不出来了），由编排层 `_remember_geometry` 写回配置。任务管理器强杀、断电丢这一次；写不进去不影响退出（只读目录里程序本来就能照常跑，只在日志里留一句「窗口位置没记住（原因）」）。
- **怎么恢复**：`visible_geometry(saved, work_area)` 只保证「横向至少留 80px 在工作区里、顶边不跑到上边之外」，其余照搬——故意摆成半出屏的（贴边看盘）是用户的意图。没记过 → None → 不调 `geometry()`，按 Tk 默认位置开窗（首次运行的行为与改动前逐字一致）。工作区查不到时原样返回，不猜。
- **`popup._work_area` 改成公开的 `work_area(root=None)` 由主窗口复用**：不写第二份（第三处 Win32 调用这就来了，见 ticket 06 评审里「留待真有第三处 Win32 调用时再说」那条）。root 只在 SPI 查不到时当退路；编排层调用时 Tk 根窗还没建起来，传 None 就得 None。
- **实测踩到的两个坑**：
  - **负坐标拼错**：`f"{x}+{y}"` 在 x 为负时写出 `960x640+-880+80`，Tk 不认这串几何——单元测试当场抓到，改成 `{x:+d}`（符号由数字自带）。
  - **最大化时记不得**：`wm geometry` 在最大化状态给的是「铺满屏的那份大小 + 最大化之前的位置」（实测 `2560x1494+342+342`），照记下来下次就开出一个比屏幕还大、还挂在屏外的窗口。改成最大化那一趟不更新，保住上次正常状态下记的那一份。最小化不受影响（实测 Tk 给的仍是正常几何，不用特殊处理）。
- **测试**：新增 `tests/test_main_window.py` 13 个（形状识别、屏内照摆、屏外拉回、故意半出屏、负坐标、工作区不从原点起、没记过、无工作区）；`tests/test_config.py` 增 5 个（默认留空、坏值当没记过、校验点名、落盘往返、设置草稿不抹掉）。全套 229 → 247。
- **手验**（脚本 `D:/App/Temp/aurum-smoke/geometry_check.py`，临时目录、不入库；跑完把仓库根的 `config.json` 原样还原）：
  - **往返**：真入口起一份，把窗口摆到 (300,200,900,700) 关窗 → 配置记下 `1328x994+450+300`（150% 缩放下的物理像素）→ 再开一趟，窗口矩形与关窗前一模一样。
  - **设置窗口不抹掉**：进程内驱动真实 `SettingsWindow.save()`（改一项配色再保存），配置里记下的 `1024x768+10+20` 原样还在。
  - **换显示器**：往配置里塞 `900x700+5000+4000` 再启动 → 窗口被拉回工作区右下角（`GEOMETRY_KEEP` 那 80px 可见）。
  - **两条边界**：最大化后关窗不动已记的那份；正常状态关窗更新成这次的实际几何。
- **未手验/已知限制**：强杀不记（与「关闭主窗口即退出」一个口径）；不记最大化的状态本身（最大化时保住上次正常几何，下次仍是正常窗口）；记下的窗口比屏幕大时不裁大小（只保证左上角可见）；多显示器仍只按主屏工作区判断（spec 的 Out of Scope）。
- **与 spec 的关系**：不是新需求——spec 的 User Story 20 与「配置覆盖」清单里都写着「主窗口几何」，实现与它一致；本票只是把拆票时漏掉的那一条补上。
