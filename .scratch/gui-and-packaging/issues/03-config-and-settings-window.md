# 03: 设置落地——config.json 与设置窗口

**What to build:** 从主窗口打开设置窗口（非模态，可与主窗并排），可改国内/国际 × 涨破/跌破四个阈值（留空即停用）、提示音开关、高级项（刷新间隔、重新武装带比例、故障警告时长、启动时若已越线立即提醒）；非法值红字提示且不许保存（阈值为正数；同一市场两者都启用时跌破须小于涨破）；[保存][取消][恢复默认]三个出口。保存即写入 exe 同目录的 `config.json`、立即生效无需重启。配置文件缺失自动生成默认值；损坏或缺字段时照常启动（按默认值运行，坏文件备份为 `config.json.bak`）。源码顶部的配置区就此废除。

**Blocked by:** 02（主窗口上线）

**Status:** ready-for-agent

- [ ] 首次运行自动生成 `config.json`（打包运行在 exe 同目录；源码运行在仓库根）
- [ ] 设置窗口可改四个阈值、提示音开关与四项高级设置；阈值留空即停用该方向
- [ ] 校验不通过不许保存并指出具体项；[取消] 丢弃本次改动；[恢复默认] 二次确认后还原默认值
- [ ] 保存后无需重启：新阈值自下一轮刷新起生效，提示音开关立即生效
- [ ] 阈值按 Decimal 精度保存与读取（950.00 就是 950.00）
- [ ] 保存走临时文件 + 原子替换，写一半中断不产生损坏文件
- [ ] 配置文件损坏/缺字段：程序照常启动、按默认值运行、坏文件备份为 `config.json.bak`
- [ ] 源码配置区删除，可调项只来自配置文件与设置窗口
- [ ] 配置规范化与校验的纯函数测试新增并通过
