# 05: 事件记录与日志——近况上窗，档案落盘

**What to build:** 触发与故障警告汇成单一事件流，两处消费：主窗口事件记录区显示本次运行的最近 50 条；`logs/` 下按天写日志文件（触发、故障警告、故障出现与恢复、程序启动与退出、设置保存、配置回退、弹窗失败），自动清理 30 天前的旧文件。主窗口底部有[打开日志]按钮，在资源管理器中打开日志文件夹。日志明确不记录逐轮行情。

**Blocked by:** 02（主窗口上线）

**Status:** ready-for-agent

- [ ] 触发或故障警告发生时，主窗口事件记录与当日日志文件同时出现同一条内容
- [ ] 日志按天分文件（`logs/aurumwatch-YYYY-MM-DD.log`），启动时自动清理 30 天前的旧文件
- [ ] 记录覆盖：触发、故障警告、故障出现与恢复、启动/退出、设置保存、配置回退提示、弹窗失败
- [ ] 事件记录保留本次运行最近 50 条，重启即清空（与日志的分工明确：近况 vs 档案）
- [ ] [打开日志] 打开日志文件夹
- [ ] 不记录逐轮行情
