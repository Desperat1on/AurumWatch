# 04: 外观与预览——所见即所得

**What to build:** 设置窗口新增外观组：背景色、文字色、涨破色、跌破色、字体、基准字号（各处字号层级由基准派生）、弹窗停留秒数、弹窗位置（屏幕四角）、主窗口置顶；组内内嵌 1:1 预览卡片，改任一项即时反映——预览与真实弹窗调用同一套绘制函数，所见即所得。另配[试弹一次]（按当前未保存的设置弹出真实弹窗）与音效选择（系统提示音 / 自定义 WAV 文件）+[试听]。保存后新外观立即作用于主窗口与后续弹窗。

**Blocked by:** 03（设置落地）

**Status:** ready-for-agent

- [ ] 设置窗口可改配色、字体、基准字号、停留秒数、弹窗位置、主窗置顶；字号层级由基准字号派生
- [ ] 预览卡片与真实弹窗外观一致（同一套绘制函数），改任一外观项即时更新
- [ ] [试弹一次] 按当前（尚未保存的）设置弹出真实弹窗；[试听] 播放当前所选音效
- [ ] 音效可在系统提示音与自定义 WAV 文件间切换；WAV 文件缺失时回退系统提示音并提示
- [ ] [取消] 后主窗口与弹窗保持保存前的外观
- [ ] 保存后主窗口与后续弹窗立即采用新外观
- [ ] 弹窗位置在真实弹窗上生效（主屏四角）
