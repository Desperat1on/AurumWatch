# 02: 主窗口上线——行情面板取代控制台

**What to build:** 启动后出现常驻 GUI 主窗口（不再有控制台黑窗）：每个市场显示现价、行情数据时间、各启用阈值距触发的距离（已触发待回落的方向显示重新武装线与回摆所需量）、市场状态；底部有[立即刷新]按钮；取数失败时显示数据源故障与连续失败时长，不用陈旧读数冒充行情。越线弹窗照旧，但弹窗改为依附主窗口，不抢焦点、点击关闭、到点自动消失的行为不变。主窗口要显示的内容由一个纯函数（视图模型）算出，UI 只负责摆放。

**Blocked by:** 01（拆包重构）

**Status:** ready-for-agent

- [ ] 启动后出现主窗口、无控制台窗口；两市场行情随轮询刷新
- [ ] 每个市场显示：现价、行情数据时间、各启用阈值的距离、市场状态（监视中 / 已触发待回落 / 数据源故障）
- [ ] 已触发待回落的方向显示重新武装线与回摆所需量（沿用现有文案语义）
- [ ] 取数失败的轮次显示故障原因与连续失败时长，不显示陈旧读数
- [ ] 越线时弹窗照旧在屏幕角落出现：不抢焦点、点击关闭、到点自动消失
- [ ] [立即刷新] 立即取数一轮，下一轮仍按整分对齐
- [ ] 视图模型的纯函数测试新增并通过；控制台折行/写屏代码与其测试整体删除
- [ ] 关闭主窗口即退出监视
